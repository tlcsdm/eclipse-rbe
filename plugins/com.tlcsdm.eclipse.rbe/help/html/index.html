ResourceBundle Editor

The ResourceBundle Editor is an Eclipse plug-in that lets you view and edit all .properties files belonging to a Java resource bundle at the same time. Instead of opening each locale file separately, the editor aggregates them into a single multi-page editor so you can manage translations side-by-side.

Main Features

  • Edit all locale .properties files in one editor window.
  • Two layout modes: Form View (classic) and Table View (new in 1.2.0).
  • Hierarchical or flat key tree for fast navigation.
  • Warning icons for missing and duplicate translations.
  • Unicode ↔ \uXXXX conversion on read/write.
  • Key operations: add, rename, duplicate, delete, comment/uncomment.
  • Configurable key grouping, sorting and formatting.
  • New ResourceBundle wizard to create a bundle with multiple locales at once.

Getting Started

  1. Open any *.properties file that belongs to a bundle. Eclipse will offer to open it with the ResourceBundle Editor.
  2. The editor opens showing all related locale files. The first tab is the Properties page where you edit translations.
  3. Use the Form view / Table view toggle buttons at the top of the Properties page to switch layout.

See the other help pages for detailed descriptions of each UI element and preference.
