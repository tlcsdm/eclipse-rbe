New ResourceBundle Wizard

The New ResourceBundle wizard creates a set of .properties files in one step — one file per selected locale. Open it via File > New > Other… > ResourceBundle > ResourceBundle.

Wizard Fields

  1. Folder – the project folder (source directory) where the files will be created. Use the Browse… button to pick a folder from the workspace.
  2. Base name – the name shared by all generated files, without locale suffix or extension. For example, entering messages will create messages.properties, messages_fr.properties, etc. Do not include a file extension; it is added automatically.
  3. Locales – use the locale selector on the right to pick a language, country and optional variant, then click Add to add it to the list of selected locales. Select an entry in the list and click Remove to remove it. A default (language-neutral) locale file is always created.

Click Finish to generate the files and open the new bundle in the ResourceBundle Editor.
