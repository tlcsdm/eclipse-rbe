Editor UI

When you open a .properties file with the ResourceBundle Editor, a multi-page editor is shown. The pages are described below.

Properties Page

The Properties page (the first tab) is the main editing area. It contains a small toolbar at the top with two toggle buttons that let you switch the layout:

ButtonDescription
Form view The classic layout. A key tree is shown on the left; on the right there is one text area per locale for the selected key. This is the default layout.
Table view A spreadsheet-style layout (new in 1.2.0). Each row represents a key and each column represents a locale. Cells are editable directly in the table. Ideal for quickly scanning and filling missing translations.
The selected layout is saved as a preference and restored the next time you start Eclipse.

Form View

The form view has two panels:

Key Tree (left panel)

The key tree lists all keys in the resource bundle. It can be shown in two modes:

  • Hierarchical – keys are split on the separator character (default .) and shown as a tree.
  • Flat – keys are shown as a plain list.

The toolbar above the tree provides the following actions:

ActionDescription
AddCreates a new key in the bundle.
RenameRenames the selected key (or key group) across all locale files.
DuplicateCopies the selected key (or key group) to a new name.
DeleteRemoves the selected key (or key group) from all locale files.
Comment / UncommentComments or uncomments the selected key.
Copy KeyCopies the key name to the clipboard.
Expand All / Collapse AllExpands or collapses the entire key tree.
Flat / Tree layoutToggles between the flat and hierarchical tree layout.
Show only incompleteFilters the tree to show only keys that have at least one missing translation.

A filter text field lets you type part of a key name to search the tree.

Value Editors (right panel)

For the key selected in the tree, one text area is shown per locale. Each area has:

  • A locale flag and name label at the top. Click the flag/label to jump to the corresponding source editor tab.
  • A Comment checkbox – when checked, the entry is written as a comment in the .properties file.
  • A similar-value icon (appears when another key in the same locale has a very similar value). Click it for details.
  • A duplicate-value icon (appears when another key in the same locale has an identical value). Click it for details.

Table View

The table view (available from version 1.2.0) shows a grid where:

  • The leftmost column is the Key column (read-only).
  • Each subsequent column represents a locale. The column header shows the display name of the locale.
  • Cells are fully editable. Press F2 or double-click a cell to enter edit mode; press Enter or click elsewhere to commit.
  • Edits are immediately reflected in the underlying model and in the source editors, and the editor is marked dirty until you save.
The table view does not yet expose the comment/uncomment state or show similar/duplicate indicators. Use the form view for those advanced operations.

Source Editors

For every locale in the bundle there is a dedicated source editor tab that shows the raw .properties file content. You can make low-level edits here; when you switch back to the Properties page the changes are reloaded automatically.

New Locale Page

The last tab of the editor is the New… page. It lets you add a new locale to the existing resource bundle without using the wizard. Enter the locale code (language, country, variant) and click Create; the new .properties file is created and immediately opened in a new source editor tab.
